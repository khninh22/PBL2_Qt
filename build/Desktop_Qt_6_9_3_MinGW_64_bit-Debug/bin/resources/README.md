# Resources - Tài Nguyên

## 📸 Ảnh Nền Đăng Nhập

Đặt ảnh nền sân bóng vào đây với tên:

- `login_bg.jpg` (khuyến nghị)
- hoặc `login_bg.png`

### Yêu Cầu:

- **Kích thước**: 1920x1080 hoặc tương đương
- **Định dạng**: JPG hoặc PNG
- **Nội dung**: Ảnh sân bóng, cầu thủ đang chơi bóng

### Tải Ảnh Mẫu:

Bạn có thể tải ảnh từ:

- Unsplash: https://unsplash.com/s/photos/football-field
- Pexels: https://www.pexels.com/search/soccer-field/
- Pixabay: https://pixabay.com/images/search/soccer-stadium/

### Ảnh Đã Cung Cấp:

Ảnh trong prompt của bạn (cầu thủ đá bóng trong sân vận động) rất phù hợp!
Hãy lưu nó vào đây với tên `login_bg.jpg`.

---

**Nếu không có ảnh**: Hệ thống sẽ tự động hiển thị gradient màu xanh đẹp mắt.
